# Data

`oecd_icio_2025/icio_2022_8x10.npz` is a compact aggregation of OECD ICIO 2022.

`china_mrio/dual_circulation_2022_140nodes.npz` is the 14-region, 10-sector
nested account used by the dynamic MR-CGE. It combines OECD control totals with
the regional structure derived from the CEADS China MRIO source used in the
research workspace.

These files are model inputs, not raw source releases. Consult the original
OECD and CEADS terms and documentation before redistribution or downstream use.
