# V8.4 五篇统计、多尺度与接触几何文档的完整接入

V8.4 同时接入非参数统计、多元统计、时间序列分析、小波分析和接触几何五篇研究规格。V8.3 的正式结果保持冻结；V8.4 在完成新一轮正式仿真、匹配种子消融和结果审计前不更新任何终局概率。

## 状态所有权

非参数统计层只拥有估计函数、支持域、区间和验证分数。多元统计层只拥有潜变量、协方差、条件依赖与联合尾部估计。时间序列层只拥有滤波状态、制度概率、波动率、Hawkes 强度和变点概率。小波层只拥有因果系数、尺度能量、相干、散射和图小波异常。接触层只拥有军事、经济、金融和社会四类累计不可逆损失及其协态。

原模型继续唯一拥有产出、价格、库存、资本、债务、人口、伤亡、支持率、装备、网络容量与终局事件。新增层不得复制这些库存，也不得事后调整终局概率。

## 同路径闭环

每月只读取当前及历史信息。统计状态和多尺度特征进入当月 MFG 观测与成本；接触损失进入当月社会、金融、供应、指挥和恢复因子。主循环随后更新其权威库存，CGE 与 DSGE 消费更新后的损伤、物流、劳动、支付、财政、恐慌和封锁输入。DEDS 与竞争风险通过下一月权威状态接收反馈。

## 五篇文档覆盖

逐标题覆盖表由 `work/prepare_taiwan_v84.py` 写入 `outputs/taiwan_v84_traceability.json`。每个标题均映射到实现符号、角色、状态所有者、输入、输出、消费者、求解器、不变量和诊断产物。

明确不建议直接预测战争终局的方法仍提供可执行估计或验证后端，但不能替代动态多区域 CGE、开放经济 DSGE、连续多种群 MFG、DEDS、网络流、战役动力学或竞争风险模型。

## 验证边界

当前只允许执行语法、形状、概率边界、正定性、因果时钟、小波重构、接触不可逆和零效应退化等诊断。新的终局仿真必须在完整门通过、规格冻结并建立全部匹配种子消融后才能开始。
